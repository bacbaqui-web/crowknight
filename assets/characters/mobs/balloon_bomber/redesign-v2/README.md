# 허리 결속 밧줄

Built-in image generation으로 투명 PNG 생성. Prompt: one isolated vertical braided ochre rope with black hand-drawn outlines, top loop and bottom knot, transparent background, no character or text.

`tools/author_balloon_suspension.py`는 몸을 허리에서 앞으로 숙이고 머리·팔을 늘어뜨린 자세를 작성합니다. `author_small_minions.py`로 기본 몸체를 재작성할 경우 이 스크립트를 뒤에 실행합니다. 원본 PSD 및 이전 PNG는 유지합니다.
