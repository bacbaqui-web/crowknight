Audit 질문

자기 역할만 하는가? 이름과 접미사가 맞는가? 너무 커졌는가? 다른 Engine 책임을 침범했는가? 공통 시스템을 재사용하는가?

Action 파트 지도

Authoring → Trigger → Timeline → Property / Interaction / Modifier → Runtime

Action은 하나의 전용 엔진이 아니라 아래 JS들이 연결된 편집/저장/실행 흐름이다. `pose` 명칭은 Editor Action 계층에서는 제거했고, 실제 렌더링 자세 계산 계층에만 남긴다.

Runtime Flow

Input → Trigger → Action Runtime → Current Frame → Interaction Region → Combat → Render → Debug HUD

player.hitRegions는 Combat source가 아니다. player.hitRegions는 draw/edit/debug overlay용이며, Combat은 interaction_region_engine.js가 현재 Runtime frame에서 계산한 InteractionRegion을 읽는다.

접미사 역할표

역할표 미준수 / 보류 파일

현재 보류 파일은 없다. main.js는 앱 entry point라 접미사 예외로 둔다.

구조 위험 파일

책임 개수, 섞인 책임, 줄 수, 리팩토링 후보 여부를 파일 단위로 확인한다.
