# 99 Task Report

## 모바일 반응형 조작 UI 추가

### 1. 반응형 화면

- 전체 스테이지 캔버스는 기존 `syncCanvasToLayout()`에서 현재 viewport 비율에 맞춰 내부 너비를 다시 계산한다.
- 화면 폭이 바뀌어도 카메라의 X축 추적으로 주인공을 가로 중앙에 유지한다.
- 세로 카메라 높이는 데스크톱과 같은 세션 `floorScreenY` 설정을 사용한다.
- viewport 너비가 `820px` 이하이면 모바일 조작 UI가 표시된다.
- 모바일에서는 저장된 화면 배율과 수식 적용 결과에서 `0.2`를 차감해 더 넓은 게임 영역을 보여준다.
- 저장된 세팅값은 수정하지 않으며 데스크톱에서는 기존 배율을 그대로 사용한다.

### 2. 모바일 조작 UI

- 왼쪽 하단은 원을 네 개의 부채꼴 터치 영역으로 나눈 고정 방향키다.
- 각 영역을 누르는 동안 해당 방향키 입력을 유지해 드래그 방향 오인식을 제거했다.
- `Q`는 화면 오른쪽 아래 모서리를 중심으로 크게 배치해 왼쪽 위 4분의 1만 노출한다.
- `SPACE`, `W`, 향후 `E`용 빈 슬롯을 Q의 바깥 곡선을 따라 30도 간격으로 구성했다.
- 아래 슬롯은 `SPACE`, 가운데 슬롯은 `W`이며 위 슬롯은 이후 `E` 버튼 추가를 위해 비워두었다.
- 액션 버튼은 기존 `data-hold-code` 입력 경로를 재사용해 방향키와 동시에 누를 수 있다.
- Q 중심은 직전 위치보다 오른쪽 5px, 위쪽 3px 이동하고 SPACE 하단은 바닥에서 10px 띄운다.
- W와 SPACE 버튼은 직전 크기의 1.2배로 확대한다.
- 왼쪽 방향 조작 패드는 직전 크기의 1.1배로 확대한다.
- 실제 버튼 반지름을 측정해 Q와 SPACE/W의 외곽 간격을 각각 5px로 유지한다.
- W는 Q 중심에서 SPACE 방향 벡터를 위쪽으로 정확히 30도 회전한 위치에 배치한다.
- iOS safe area를 반영해 홈 인디케이터와 조작 버튼이 겹치지 않도록 했다.

### 3. 접근성 및 표시

- 각 버튼에 동작을 설명하는 `aria-label`을 추가했다.
- 모바일 시작 화면은 `crow_knight_title.webp`, 데스크톱은 `crow_knight_title_2.webp`를 사용한다.
- 모바일 타이틀 에셋의 불투명 영역은 좌우 중심 오차가 0.5px뿐이므로 에셋 편향이 없음을 확인했다.
- 모바일 시작 화면을 명시적인 단일 열로 만들고 picture와 PLAY 버튼을 각각 중앙 정렬하며 타이틀만 왼쪽 10px, 위쪽 3px 이동했다.
- 모바일 조작 패드는 실제 Run 중에만 표시하고 타이틀, 사망 연출, 결과 화면에서는 숨긴다.
- 모바일 결과 화면에서는 응원 말풍선을 렌더링하지 않으며 breakpoint 변경 시 활성 상태를 다시 계산한다.
- 데스크톱 결과 말풍선은 결과창보다 앞에 표시하되, 실제 말풍선 크기와 결과 패널 경계를 측정해 패널 상·하·좌·우의 여유 공간에만 생성한다.
- 말풍선의 이동 범위보다 큰 32px 간격을 확보해 떠다니는 동안에도 중앙 결과 패널을 가리지 않게 했다.
- 각 말풍선마다 최소 36개의 배치 후보를 평가하고 기존 말풍선과의 겹침 면적이 가장 작은 위치를 선택한다.
- 겹침이 같은 후보는 가장 가까운 말풍선과 더 멀리 떨어진 위치를 우선하며, 최대 drift 18px을 충돌 여백에 포함한다.
- 모바일 결과 패널은 `획득 점수 및 등록 폼 → 다시하기와 외부 링크 아이콘 → 랭킹` 순서로 표시한다.
- 결과 화면의 `획득 점수` 제목을 제거하고 총점을 가운데 정렬해 기존의 두 배 크기로 강조한다.
- 총점 아래에는 `생존 · 잡몹 처치 · 보스 처치`를 한 줄 3열로 표시한다.
- 점수 산식은 `생존 초 × 5 + 잡몹 처치 × 100 + 보스 처치 × 1,000`이다.
- 전투 사망 콜백이 사망 Actor를 전달하므로 잡몹과 보스를 중복 없이 분리 집계한다.
- 플레이 중 상단 HUD도 생존 시간, 잡몹 처치 수, 보스 처치 수 세 항목을 실시간 표시한다.
- 상단 HUD의 아이콘, 글자, 높이와 간격을 줄여 게임 화면을 덜 가리게 했다.
- 데스크톱과 모바일 좌측 상단에 Run 중에만 표시되는 `조작법` 버튼을 추가했다.
- 조작법을 열면 게임 업데이트와 생존 시간 집계를 멈추고 기존 데스크톱 조작법 패널을 화면 중앙에 표시한다.
- 이후 키 입력이나 화면 pointer 입력이 발생하면 패널을 닫고 입력 상태와 frame 시각을 초기화한 뒤 게임을 재개한다.
- 조작법 항목에 좌우 방향키 두 번 입력인 `질주`를 추가하고 백플립을 구르기 바로 아래로 이동했다.
- 점프공격과 낙하공격 입력은 `공중 + Q`, `공중 + ↓ + Q`로 안내한다.

### 5. 코덱스 의견

- 모바일 입력이 별도 게임 로직을 만들지 않고 키보드 입력 집합을 공유하므로 액션 Trigger 설정과 동작이 일치한다.
- 실제 휴대전화에서 가로/세로 전환, 두 손가락 동시 입력, iOS 하단 safe area를 한 차례 수동 확인하는 것이 좋다.
