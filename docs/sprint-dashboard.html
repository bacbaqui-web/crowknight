Effect playbackRate Runtime draw 연결

Task 목표

  • Effect 애니메이션 속도 설정이 저장되는지 확인한다.
  • Preview와 Runtime이 같은 Effect playback source를 쓰는지 확인한다.

완료 내용

  • `drawAttackTrail()`의 Effect 진행률 계산 경로를 확인했다.
  • Runtime Effect draw가 `effectSettings.duration / playbackRate / playback`을 읽도록 수정했다.
  • Action Preview 중에는 기존 `getActionFrameProgress()` 동작을 유지했다.

남겨둔 범위

  • Effect 속도 체감은 브라우저에서 실제 재생으로 추가 확인이 필요하다.
  • 실제 수동 플레이 체감 QA는 사용자가 이어서 확인한다.
