Task 이름

고정 Formula 반대 방향 옵션

Task 목표

  • 고정 Formula 방향 선택에 `반대` 옵션을 추가한다.
  • 활성 구간 동안 플레이어의 반대 방향을 바라보게 한다.
  • 적 자동 주시보다 고정 Formula를 우선 적용한다.

완료 내용

  • `direction: "away"` 저장값을 추가했다.
  • NPC motion 단계에서 플레이어와 actor 위치를 비교해 반대 방향 facing을 계산한다.
  • 기존 `left` / `right`와 mirror 계산은 유지했다.

남겨둔 범위

  • 브라우저에서 궁수 / 보스 Action에 `반대`를 설정한 뒤 실제 facing 확인이 필요하다.
  • 플레이어가 좌우로 지나갈 때 반대 방향이 즉시 갱신되는지 확인이 필요하다.
