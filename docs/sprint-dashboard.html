2. 직전 완료 Task 보고

Task 이름

보스 처치 HP 회복 기믹 추가

Task 목표

  • 보스 1명 처치마다 주인공 HP를 1 회복한다.
  • 같은 보스 사망으로 회복이 중복 실행되지 않게 한다.
  • 보스 처치 시 화면 중간 위에 `HP+1` 알림을 표시한다.

완료 내용

  • `main.js`의 `handleEnemyDeath()`에서 Boss 처치 회복을 연결했다.
  • `playerActor.hpPips`를 `maxHpPips`까지만 1 회복한다.
  • `index.html`과 `rankingScreens.css`에 `HP+1` 알림 UI를 추가했다.
  • 알림 queue를 사용해 여러 알림이 겹치지 않도록 했다.

남겨둔 범위

  • 브라우저에서 실제 보스 처치 후 HP 회복과 `HP+1` 표시를 수동 확인해야 한다.
  • HP가 이미 최대일 때도 알림은 보상 피드백으로 표시된다.
