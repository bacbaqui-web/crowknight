Action Projectile Formula MVP

Task 목표

  • Action Formula Library에 투사체를 추가한다.
  • 발사 frame에서 player 위치를 목표로 고정한 포물선 projectile을 생성한다.
  • Projectile hitbox를 기존 Combat hit 경로에 연결한다.

완료 내용

  • `projectile_runtime_engine.js`가 Runtime 전용 projectile pool을 관리한다.
  • Projectile Formula는 `actionSettings[actionKey].formulas[]`에 저장한다.
  • 기존 Effect asset은 projectile 그림으로만 재사용한다.

남겨둔 범위

  • 브라우저에서 궁수 여러 명 동시 발사 수동 QA가 필요하다.
