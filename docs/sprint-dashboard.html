최종 목표

2. 직전 완료 Task 보고

Task 이름

knockback velocity impulse 보존

Task 목표

  • Attack Region의 knockback 값이 Combat에 전달되는지 확인한다.
  • Combat에서 대상 velocity가 실제로 변하는지 확인한다.
  • World Physics 관성 때문에 첫 이동 전에 velocity가 죽는지 확인한다.

완료 내용

  • `applyKnockback()`이 `target.player.vx`를 갱신하는 것을 확인했다.
  • 넉백 후 `velocityControl.x = true`를 설정해 다음 physics frame에서 감쇠 전 이동되게 했다.
  • Interaction 저장 구조와 damage 판정은 변경하지 않았다.

남겨둔 범위

  • 브라우저 체감 QA는 사용자가 이어서 확인한다.
  • 장기적으로 knockback 전용 velocity 채널 분리를 검토할 수 있다.
