  • Run Actor와 lifecycle의 Source of Truth 및 분리 후보를 기록했다.
  • 회귀 위험, 단계별 완료 조건과 GPT 검토 질문을 작성했다.

  • main.js, combat_engine.js와 최신 Formula·Runtime 책임 및 파일 크기를 반영했다.

남겨둔 범위

  • 현재는 계획 초안이며 Runtime 구현은 시작하지 않았다.
