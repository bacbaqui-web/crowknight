2. 직전 완료 Task 보고

Task 이름

Action Zoom Formula 추가

Task 목표

  • Action Formula Library에 확대를 추가한다.
  • 미니 타임라인 구간 동안 설정 배율을 화면에 적용한다.
  • 프로젝트 기본 화면 배율 저장값은 변경하지 않는다.

완료 내용

  • `zoom_formula_runtime_helper.js`가 활성 확대 Formula 배율을 계산한다.
  • 저장 구조는 `actionSettings[actionKey].formulas[]`의 `type: "zoom"`이다.
  • Camera view에는 기본 배율과 활성 Formula 배율 중 큰 값을 전달한다.

남겨둔 범위

  • 브라우저에서 Action 구간별 확대 적용 수동 QA가 필요하다.
  • 여러 actor가 동시에 확대 Formula를 켜면 가장 큰 배율을 사용한다.
