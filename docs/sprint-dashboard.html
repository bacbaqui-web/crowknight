1. Sprint 정보

Sprint 이름

Background 반복 브라우저 확대율 안정화

최종 목표

브라우저 zoom / devicePixelRatio 변화에도 PSD background 반복 경계가 동일하게 보이도록 한다.

2. 직전 완료 Task 보고

Task 이름

Background 반복 edge를 device pixel 기준으로 정렬

Task 목표

  • tileWidth는 World 좌표 기준으로 유지한다.
  • 브라우저 zoom으로 달라지는 fractional pixel seam을 제거한다.
  • Canvas 전체 DPR 구조 변경 없이 Background 경계만 최소 수정한다.

완료 내용

  • PSD layer tileWidth가 DPR을 직접 쓰지 않는 것을 확인했다.
  • 반복 타일 destination edge를 현재 devicePixelRatio 기준으로 정렬했다.
  • 기존 임의 `+1px` overlap 보정을 제거했다.

남겨둔 범위

  • 실제 브라우저 zoom 50/80/100/125/150/200 화면 수동 QA가 필요하다.
  • Canvas 전체 DPR transform 공통화는 별도 Sprint로 분리하는 편이 안전하다.
